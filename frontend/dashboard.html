Metric Reference
All formulas and definitions from the CAEM methodology.
CEI
Cost Elasticity Index
Measures how efficiently cloud costs respond to workload changes. High CEI means costs scale proportionally with value delivered.
avg(|DeltaCost| / |DeltaWorkload|) normalized to [0,1]
SVS
Sprint Velocity Stability
Measures consistency of sprint delivery. High SVS indicates predictable team output and reliable planning.
SVS = 1 - (sigma / mu) of velocity series
RRE
Resource Reallocation Efficiency
Share of cloud resources that are optimally allocated versus idle or wasted. Directly reflects operational efficiency.
RRE = OptimalResources / TotalResources
CAS
Cloud-Agile Synergy Coefficient
The central composite index of the CAEM model. Weighted combination of all three sub-indices. Target threshold: 0.70+.
CAS = w1*CEI + w2*SVS + w3*RRE; w1+w2+w3=1
Hes
Hybrid Efficiency Score
Composite efficiency computed server-side combining cloud and agile efficiency signals. Used as input to ML models.
Hes = f(cost, velocity, IaC, deployment_freq)
CASI
Cloud-Agile Synergy Index
Server-side refined version of CAS incorporating infrastructure complexity, dependency graph, and elasticity factor.
CASI = CAS * El * (1 - Dk) * R2V
Maturity Levels
Elastic Agile Maturity Model (EAMM)
L1 Static - manual, unpredictable. L2 Reactive - responds to failures. L3 Proactive - anticipates needs. L4 Predictive - ML-driven forecasting. L5 Autonomous - self-healing, zero-touch operations.
